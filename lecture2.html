Lecture 2

Tiered Web Architecture

Separation of concerns: one-tier, two-tier and three-tier systems

Summary

This lecture explains how web systems are organised into tiers. It compares one-tier, two-tier and three/n-tier architecture, explains the difference between tiers and layers, and shows how to choose an architecture using scalability, maintainability and cost.

Topics Covered

  • Basic Ideas
    • Tier = physical separation
    • Layer = logical responsibility
  • Architectures
    • One-tier: standalone application
    • Two-tier: client and server
    • Three/N-tier: presentation, application, data
  • Choosing
    • Scalability
    • Maintainability
    • Cost
