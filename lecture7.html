Lecture 7

Positioning, z-index and Floats

Normal flow, the position property, stacking order and floats

Summary

This lecture starts from normal document flow and then explains static, relative, absolute, fixed and sticky positioning with the containing block. It also covers z-index and stacking contexts, and floats with clear and the clearfix technique.

Topics Covered

  • Normal Flow and Position
    • Normal document flow
    • static and relative
    • absolute and the containing block
    • fixed and sticky
  • Stacking
    • z-index
    • Stacking contexts
  • Floats
    • float: left and right
    • clear and clearfix
    • Float vs Flexbox

Example Code

.card  { position: relative; }

.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}
