Lecture 4

Semantic HTML, Forms and Validation

Giving meaning to a page and collecting user input

Summary

This lecture covers block and inline elements, div and span, and the HTML5 semantic elements that make a page accessible and SEO friendly. It then explains forms: action and method, labels, input types, select, textarea, buttons, and HTML5 validation with required, pattern, min and max.

Topics Covered

  • Meaning
    • Block vs inline elements
    • div and span
    • header, nav, main, section, article, aside, footer
  • Forms
    • action and method
    • label, input, select, textarea, button
    • fieldset and legend
  • Validation
    • required
    • pattern
    • min and max
    • Client vs server validation

Example Code

<form action="#" method="post">
  <label for="reg">Reg No:</label>
  <input id="reg" name="reg" required
         pattern="FA[0-9]{2}-BSE-[0-9]{3}">
  <button type="submit">Register</button>
</form>
