Lecture 8

CSS Effects, Animations and Media Queries

Visual effects, motion, fonts, variables and responsive CSS

Summary

This lecture covers visual effects (border-radius, gradients, box-shadow, opacity), 2D/3D transforms, transitions and keyframe animations. It then explains web fonts, icon fonts and CSS custom properties, and finishes with media queries, feature queries and cross-browser compatibility.

Topics Covered

  • Visual Effects
    • border-radius
    • Linear and radial gradients
    • box-shadow and opacity
  • Motion
    • transform: translate, rotate, scale, skew
    • transition
    • @keyframes and animation
  • Fonts and Variables
    • @font-face and web fonts
    • Icon fonts
    • Custom properties with var()
  • Responsive and Compatible
    • @media queries
    • @supports
    • Vendor prefixes

Example Code

.btn {
  border-radius: 999px;
  background: linear-gradient(90deg, #376fb4, #48a9a6);
  transition: transform 0.3s ease;
}

.btn:hover {
  transform: scale(1.1);
}
