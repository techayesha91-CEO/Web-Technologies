Lecture 5

CSS Basics: Syntax, Selectors and Cascade

How CSS selects elements and decides which rule wins

Summary

This lecture introduces CSS and its syntax, the three ways of adding CSS (inline, internal, external), and the different selectors. It explains pseudo-classes and pseudo-elements, the cascade, specificity and inheritance, and the basic colour, font, text and background properties.

Topics Covered

  • Syntax
    • Selector, property and value
    • Inline, internal and external CSS
  • Selectors
    • Element, class, id and attribute
    • Grouping, descendant, child and sibling
    • Universal selector
  • Pseudo and Cascade
    • Pseudo-classes: hover, focus, nth-child
    • Pseudo-elements: before, after
    • Cascade, specificity and inheritance
  • Appearance
    • Colour: HEX, RGB, RGBA
    • Font, text and background properties

Example Code

p     { color: green; }
.note { color: blue; }
#intro { color: red; }

<p id="intro" class="note">Hello CSS</p>

Output

Hello CSS

The id selector has the highest specificity, so the text is red.
