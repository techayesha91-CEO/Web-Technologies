Lecture 6

CSS Box Model and Display

Content, padding, border and margin; sizing and display

Summary

This lecture explains that every element is a box made of content, padding, border and margin. It covers box-sizing, margin collapsing, width and height with min/max limits, overflow, and the display property (block, inline, inline-block, none).

Topics Covered

  • Box Model
    • Content, padding, border, margin
    • Padding and margin shorthand
    • Margin collapsing
  • Sizing
    • content-box vs border-box
    • min/max width and height
    • overflow
  • Display and Style
    • block, inline, inline-block, none
    • Borders and box shadows
    • Consistent spacing

Example Code

.box {
  width: 250px;
  padding: 20px;
  border: 5px solid black;
  margin: 30px;
}

/* Total width = 250 + 20 + 20 + 5 + 5 = 300px */

Output

Content

Total box width = 250 + 20 + 20 + 5 + 5 = 300px
