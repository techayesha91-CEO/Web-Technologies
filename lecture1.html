Lecture 1

Introduction to the Web

Internet vs Web, how websites are served, standards and web application types

Summary

This lecture explains the difference between the Internet and the World Wide Web, what is needed to create and publish a website, and how a browser and a web server communicate. It also covers URLs, DNS, HTTP/HTTPS, web standards, the history of HTML and the main types of web applications.

Topics Covered

  • Internet and Web
    • Internet vs World Wide Web
    • Web platforms and examples
  • How the Web Works
    • Client-server request and response
    • URL, URI and DNS
    • HTTP/HTTPS, methods and status codes
  • Standards and History
    • W3C, WHATWG, ECMA and IETF
    • From HTML 1989 to HTML5
  • Web Application Types
    • Static and dynamic
    • MPA, SPA and PWA
