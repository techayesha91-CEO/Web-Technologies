Lecture 3

HTML Fundamentals

Document structure, content elements and HTML5 features

Summary

This lecture introduces HTML as the structure of a web page. It covers the document structure, tags, elements and attributes, correct nesting, validation, and content such as headings, links, images, media, lists and tables. It ends with the main HTML5 features.

Topics Covered

  • Structure
    • DOCTYPE, head and body
    • Tags, elements and attributes
    • Nesting and W3C validation
  • Content
    • Headings, paragraphs and text formatting
    • Links: absolute, relative, fragment
    • Images, audio and video
    • Lists and tables (thead, tbody, colspan)
  • HTML5
    • Viewport meta tag
    • Canvas and localStorage

Example Code

<table>
  <tr><th>Name</th><th>Marks</th></tr>
  <tr><td>Ali</td><td>85</td></tr>
  <tr><td>Sara</td><td>91</td></tr>
</table>

Output

NameMarks
Ali85
Sara91
